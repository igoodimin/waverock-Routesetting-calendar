# 결정 기록

## 2026-10-12 — 고정 5주와 월 경계 누락 방지
- 디자인은 5주·35칸으로 유지한다.
- 1일이 목~토이면 첫 주 제외를 우선한다. 그 외 말일이 일~화이면 마지막 주를 제외하고 앞 주를 포함한다.
- 말일 수요일은 마지막 주를 유지한다. 기존 규칙에서는 2026년 9월이 9/26에 끝나고 10월이 10/4에 시작해 9/27~10/3이 누락되었다. 사용자가 예외 적용을 승인했다.
- 변경 후 1900~2200년 모든 월을 대상으로 인접 월을 포함한 날짜 누락 없음 검증을 통과했다.

## 출력 및 검증 분담
- 디자인 좌표 1080×1350, PNG 출력 2160×2700px 및 150dpi 메타데이터를 사용한다.
- 사용자 요청에 따라 브라우저 동작·실제 PNG 출력 검증은 사용자가 수행한다. 자동 검증 결과와 실제 출력 확인 여부를 구분한다.

## 2026-10-12 — 카드 표시와 일정 입력
- 지점별 배경·로고 색상은 제공 SVG를 기준으로 한다. 원본을 보존하고 작은/큰 카드별 로고를 추출해 사용한다.
- 하루(한 칸) 카드는 공간에 맞춰 로고 오른쪽에 섹터명 21px과 시간을 중앙정렬하고 안내 문구를 숨긴다. 사용자 요청으로 섹터명 기준선을 2px 내렸다. 중복 적층 시 기존 비례 축소를 유지한다.
- 날짜 선택 후 팝업에서 내용을 지정하고 저장할 때만 일정을 생성한다. 취소 시 불필요한 일정이 남지 않도록 신규 입력은 저장 전까지 이벤트 목록에 추가하지 않는다.
- 지점별 지정 섹터는 드롭다운으로 선택하고, 예외 이름을 지원하기 위해 직접 입력도 유지한다. 지점을 바꿀 때 기존 입력은 보존한다.
- 사용자가 후속 UI 수정 검증을 맡겠다고 요청하여 에이전트는 해당 수정의 테스트·브라우저 검증을 실행하지 않았다.

## 2026-10-12 — 공개 웹 배포 준비와 공용 저장
- 사용자가 GitHub 업로드·웹 공개를 목표로 폰트 전환과 공용 저장 구현을 승인했다.
- Pretendard는 공식 안내의 cdnjs 1.3.9를 사용한다. Arial Black은 기기 설치본만 사용하며 미설치 시 Pretendard 900으로 대체한다. 프로젝트 내 폰트 사본을 제거했다.
- 사용자가 로그인 없이 누구나 조회·편집하는 단일 공용 달력과 새 Supabase 프로젝트 사용을 명시적으로 선택했다. 모든 방문자에게 삭제 권한도 있으며 사용자별 공간은 없다.
- 일정별 REST 저장 및 버전 비교로 같은 일정의 동시 수정 충돌을 감지한다. 조회는 10초 간격이며 편집 중에는 보류한다. 기존 로컬 일정은 공용 서버로 자동 이관하지 않는다.
- 사용자 요청으로 앱·폰트·PNG 검증은 사용자가 담당한다. 이후 사용자가 Supabase 설정 직접 실행을 요청하고 익명 삭제 권한까지 명시적으로 승인하여 스키마 실행 성공을 확인했다. 연결 정보도 config.mjs에 반영했다. 이후 사용자가 GitHub 업로드·GitHub Pages 배포 및 배포 앱 저장 검증을 직접 완료했다고 보고했다(2026-10-12).
