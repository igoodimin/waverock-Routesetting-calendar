# 공휴일 데이터와 적용 방법

## 데이터
- `holidays.mjs`에 2026·2027년 한국 공휴일을 수록했다. 다른 연도는 자동 계산하지 않으며 UI에서 지원 범위를 안내한다.
- 대체공휴일, 설·추석 연휴, 2026년 지방선거일을 포함한다. 노동절·제헌절은 2026년 공휴일 지정 변경을 반영한다.
- 새 연도와 추후 지정 임시공휴일은 공식 발표 확인 후 데이터를 갱신해야 한다. 사용자는 날짜 팝업에서 직접 추가할 수 있다.

  - [한국천문연구원 2027년 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2027)

## 공용 저장 적용
1. 기존 테이블이 있는 Supabase 프로젝트의 SQL Editor에서 Query source를 Database로 설정한다.
2. `supabase/holidays.sql`을 한 번 실행한다. 기존 `schema.sql`은 다시 실행하지 않는다.
3. 앱 파일을 배포한 뒤 새로고침한다.
- 에이전트는 SQL 실행·배포·검증을 수행하지 않았다.
- 테이블 연결 실패 시 기존 일정 기능과 기본 공휴일 표시는 유지한다. 수정 공휴일 동기화 실패를 상태에 알리고 공휴일 저장은 차단한다.

## 사용자 확인 항목
- 2026년 10월 3일 개천절, 5일 대체공휴일, 9일 한글날: 일요일과 같은 빨강, 날짜 아래 이름, 오른쪽 정렬.
- 날짜 클릭 팝업 맨 아래에서 이름 변경 → 공휴일 저장. 세팅 일정이 새로 생기지 않는지 확인.
- 일반 날짜 직접 입력, 표시 해제, 자동 표시 복원, 새로고침 및 다른 기기 동기화.
- 일정 클릭·드래그, 여러 날 일정, 중복 적층, PNG 출력. 공휴일이 있는 주는 적층 카드가 공휴일명과 겹치지 않도록 높이를 줄임.
- 공휴일 설정은 적용 날짜 한 날짜에만 저장한다. 드래그 시 초기 적용 날짜는 선택 시작일이며 별도로 변경 가능하다.
- 일정 저장과 공휴일 저장은 독립적이며 각각 버튼을 눌러야 한다. 저장하지 않고 닫으면 입력은 버려진다.
